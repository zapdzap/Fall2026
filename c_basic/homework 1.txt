Questions:
    1. Convert decimal 95 to hexadecimal.
       Answer: 0x5F
       Reasoning: 16 goes into 95 five times with a remainder of 15. 15 in hexadecimal is F.
           
    2. Convert 0x1CD to unsigned decimal. (Hint: Convert it to binary first!)
       Answer: 461
       Reasoning: The binary of 0x1CD is 0001 1100 1101, 1 + 4 + 8 + 64 + 128 + 256 = 461
       
    3. What is the value of binary 10101011 in decimal if this is a negative number?
	   Decimal Answer: -85
	   Reasoning: The complement of 10101011 is 01010101. 1 + 4 + 16 + 64 = 85. Since the original number is negative, the answer is -85.

	8. Suppose current value of the register is 0xC1. You are asked to set ONLY the ODR2 bit in P1_ODR to 1. What will be new register value?
		Hexadecimal Answer: 0xC5
			Reasoning: The current register value is 0xC1, in binary that's 11000001. Setting p1 to 1 means we need to set the 2nd bit to 1. This would just be adding 4 to our hexadecimal value. 0xC1 + 0x04 = 0xC5. The new register value is 0xC5.
			

	9. Suppose current value of the register is 0xC1. You are asked to set ODR2 & ODR5 bits in P1_ODR to 1 AND clear 0DR0 bit (i.e. set to zero). What will be new register value?
		Hexadecimal Answer: 0xC4
			Reasoning: The current register value is 0xC1, in binary that's 11000001. Setting p1 to 1 means we need to set the 2nd and 5th bits to 1. This would just be adding 4 + 32 = 36 to our hexadecimal value. Then we just subtract 1 from our hexadecimal value to clear the 0DR0 bit. 0xC1 + 0x04 + 0x20 - 0x01 = 0xC4.
