TCP vs UDP

TCP (Transmission Control Protocol) and UDP (User Datagram Protocol) are two core transport layer protocols used to send data across a 
network. TCP is a reliable, connection-oriented protocol that guarantees data delivery in the correct order, while UDP is a fast, 
connectionless protocol that sends data quickly without delivery guarantees.

 TCP - (Transmission Control Protocol)Connection-Oriented: Uses a "three-way handshake" to set up a connection between devices before
 sending any data. Reliable & Ordered: Checks for lost packets, requests retransmission of missing data, and sorts packets into the 
 correct sequence upon arrival. Flow & Congestion Control: Adjusts transmission speeds to match network capacity and prevent data loss.
 Higher Overhead: Uses larger headers (20 to 60 bytes) for tracking and error-checking.
 Best Use Cases: Web browsing (HTTP/HTTPS), email (SMTP), file transfers (FTP/SFTP).
 
 UDP - (User Datagram Protocol)Connectionless: Sends data immediately without a handshake or checking if the receiver is ready 
 ("fire-and-forget").Unreliable & Unordered: Does not track delivery, retransmit lost packets, or guarantee order.
 Lightweight & Fast: Minimal overhead with a tiny 8-byte header, making it much faster than TCP.
 Best Use Cases: Live video streaming, online multiplayer gaming, voice/video calls (VoIP), and DNS lookups.
